# GCA 문화기술 기업 탐사 다이브

2026 경기도 문화기술 산업육성 사업 참여기업 31개사를 바닷속 다이빙으로 만나는 기업 소개 페이지입니다.

- 공개 주소: https://gca-ct-dive.github.io/
- 만든 곳: 경기콘텐츠진흥원 콘텐츠산업팀
- 구성: `index.html` 한 파일 (기업 정보·로고 포함). 3D 다이버는 Three.js(cdnjs), 글꼴은 Google Fonts를 불러옵니다.
- 누적 방문자 수는 abacus.jasoncameron.dev 카운터로 집계하며, 같은 브라우저는 한 번만 셉니다.

## 이용 안내

본 페이지는 2026 경기도 문화기술 산업육성 사업 지원기업 소개를 위해 경기콘텐츠진흥원이 제작했습니다. 각 기업의 로고와 상표에 대한 권리는 해당 기업에 있으며, 연결된 외부 사이트의 내용은 각 기업이 책임집니다. 이 페이지는 개인정보를 수집하지 않습니다.
